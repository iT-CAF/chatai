**An open-source iOS chat app on the OpenAI API, with a beginner-friendly publishing guide.**

An AI chat app for iOS with a step-by-step beginner guide: run it in Xcode, set the bundle ID and version, archive, and ship to TestFlight / App Store or export an IPA.

## `>` Features · المزايا

| Feature | الميزة |
|:--|--:|
| Ready Xcode project (CAFGPT-main) | مشروع Xcode جاهز (CAFGPT-main) |
| Step-by-step archive & upload guide | دليل الأرشفة والرفع خطوة بخطوة |

## `$` Build & ship · التشغيل والنشر

1. افتح المشروع في Xcode · Open the project in Xcode
2. اختر شهادة المطوّر وغيّر Bundle ID والإصدار · Set signing, bundle ID and version
3. اختر Any iOS Device (arm64) ثم Product › Archive · Product › Archive
4. Distribute App › App Store Connect (أو آخر خيار لتصدير IPA) · or export an IPA
